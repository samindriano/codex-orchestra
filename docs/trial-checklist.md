# Lightweight Astra trials

Use comparable, meaningful tasks where possible:

1. Astra Medium DIRECT.
2. Astra Medium plus one Luna XHigh worker.
3. Astra Medium plus 2–3 useful independent Luna XHigh workers.

Record the following once at start/end, without adding ceremony to every step:

| Early context forgotten? Concrete example | |
| Context search recovered earlier evidence? Reference | |
| Independent review: useful finding or no added value | |
| Context experiment enabled / runtime version | |

Allowances are account-wide; concurrent tasks and reset boundaries confound deltas.
Treat a reset as a discontinuity, not negative consumption. Do not attribute shared
usage to one root without evidence. Compare useful decision-changing work per quota
consumed, alongside quality, time, and steering. Do not optimize solely for tokens.
A few bounded trials are observations, not a causal quota benchmark.
